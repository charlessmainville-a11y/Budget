# Dead-Simple Browser Music App

1. Create a new GitHub repository.
2. Upload **both files** to the repo root: `index.html` and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment → Source**, select:
   - **Deploy from a branch**
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Click **Save**.
6. Wait about **30–60 seconds**.
7. Open the Pages link shown on that screen.

If it does not open yet, refresh once and wait another 30 seconds.
